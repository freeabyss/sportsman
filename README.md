# 国乒排行榜 🏓

中国乒乓球运动员个人历史竞技成就统计与排名系统。

## 概述

国乒排行榜是一个纯前端页面，展示中国乒乓球运动员在奥运会、世锦赛、世界杯三大赛中的个人历史竞技成就排名。系统基于赛事权重、项目权重和奖牌权重计算积分，并提供胜率模型计算统治力指数（辅助展示，不计入积分）。

榜单目标：**评价中国乒乓球运动员个人历史竞技成就，而非国家队整体成绩。**

## 核心功能

- **排行榜** - 综合排名，支持综合/现役/男女筛选，TOP3卡片展示
- **运动员详情** - 基础资料、荣誉概览、奖牌矩阵、三大赛成绩、比赛历史、对手关系
- **积分分析** - 积分拆解：三大赛贡献、项目贡献的可视化展示
- **赛事浏览** - 赛事列表、赛事详情、项目详情、奖牌分布
- **比赛详情** - 比分展示、局比分、对阵信息

## 技术栈

- Vue 3 (Composition API)
- Vue Router 4
- Vite
- 纯静态 JSON 数据

## 排名规则（V1.0）

### 一、榜单定位

评价对象：中国乒乓球运动员在世界最高级别赛事中的**个人历史竞技成就**。

核心原则：

1. 评价运动员本人，而非国家队整体成绩。
2. 三大赛并列为最高级别赛事，不人为区分赛事权重。
3. 单打是评价个人竞技能力的核心。
4. 双打、混双属于个人竞技成就，但个人属性弱于单打。
5. 团体成绩计入，但作为辅助性竞技成就。
6. 金、银、铜均计分，体现运动员长期稳定的世界顶级竞争能力。
7. 同一赛事的不同项目分别计分，可以累加。

### 二、统计赛事范围

V1.0 仅统计三大赛，赛事权重统一为 **100**，不区分奥运会、世锦赛、世界杯的赛事基础价值：

| 赛事       | 赛事权重 |
| ---------- | -------: |
| 奥运会     |      100 |
| 世锦赛     |      100 |
| 世界杯     |      100 |

### 三、项目权重

| 项目 |  权重 |
| ---- | ----: |
| 单打 | 1.00  |
| 双打 | 0.60  |
| 混双 | 0.60  |
| 团体 | 0.30  |

单打 > 双打/混双 > 团体，是整个榜单最重要的价值判断。

### 四、奖牌权重

| 奖牌 |  权重 |
| ---- | ----: |
| 金牌 | 1.50  |
| 银牌 | 0.60  |
| 铜牌 | 0.35  |

既突出冠军，又不会完全忽略亚军和季军。

### 五、最终积分公式

每一项成绩单独计算：

```
积分 = 赛事权重 × 项目权重 × 奖牌权重
     = 100 × 项目权重 × 奖牌权重
```

### 六、积分矩阵

| 项目     |   金牌 |  银牌 |   铜牌 |
| -------- | -----: | ----: | -----: |
| **单打** |  **150** |  **60** |  **35** |
| **双打** |   **90** |  **36** |  **21** |
| **混双** |   **90** |  **36** |  **21** |
| **团体** |   **45** |  **18** | **10.5** |

### 七、排序规则

第一排序条件：总积分从高到低。

总积分相同时，依次使用以下辅助指标：

1. 三大赛单打金牌数量
2. 三大赛单打奖牌数量
3. 三大赛全部金牌数量
4. 三大赛全部奖牌数量

### 八、V1.0 暂不考虑的因素

第一版不加入：年代修正、对手强度修正、参赛人数修正、比赛轮次修正、世界排名修正、连冠奖励、连续参赛奖励、年龄修正、退役时间修正、主场优势修正、赛事周期修正。

也就是说：**只看最终取得的三大赛成绩。**

### 九、统治力指数（辅助展示，不计入积分）

```
统治力 = 生涯胜率×40% + 中国内部胜率×40% + 顶级赛事胜率×20%
```

## 数据范围

- 统计对象：代表中国乒乓球队参加三大赛的运动员
- 数据来源：ITTF、中国乒乓球协会、WTT官方数据
