# 国乒排行榜 🏓

中国乒乓球运动员个人历史竞技成就统计与排名系统。

## 概述

国乒排行榜是一个纯前端页面，展示中国乒乓球运动员在奥运会、世锦赛、世界杯三大赛中的个人历史竞技成就排名。排名仅依据三大赛奖牌数量，不计算积分、不引入胜率或统治力模型。

榜单目标：**评价中国乒乓球运动员个人历史竞技成就，而非国家队整体成绩。**

## 核心功能

- **排行榜** - 综合排名，支持综合/现役/男女筛选，TOP3卡片展示
- **运动员详情** - 基础资料、荣誉概览、奖牌矩阵、三大赛成绩、比赛历史、对手关系
- **赛事浏览** - 赛事列表、赛事详情、项目详情、奖牌分布
- **比赛详情** - 比分展示、局比分、对阵信息

## 技术栈

- Vue 3 (Composition API)
- Vue Router 4
- Vite
- 纯静态 JSON 数据

## 排名规则（V1.0）

### 一、榜单定位

评价对象：中国乒乓球运动员在世界最高级别赛事中的**个人历史竞技成就**。

核心原则：

1. 评价运动员本人，而非国家队整体成绩。
2. 三大赛并列为最高级别赛事，不区分赛事权重。
3. 单打是评价个人竞技能力的核心。
4. 双打、混双属于个人竞技成就，但个人属性弱于单打。
5. 团体成绩计入，但作为辅助性竞技成就。
6. 金、银、铜均计入排名，体现运动员长期稳定的世界顶级竞争能力。
7. 同一届赛事的不同项目分别计入，可以累加。

### 二、统计赛事范围

V1.0 仅统计三大赛，不区分奥运会、世锦赛、世界杯的赛事基础价值：

| 赛事   |
| ------ |
| 奥运会 |
| 世锦赛 |
| 世界杯 |

### 三、排名优先级

排名按以下层级从高到低，前一层级相同才比较下一层级：

1. **单打**奖牌（男单 / 女单）
2. **双打 / 混双**奖牌（男双 / 女双 / 混双）
3. **团体**奖牌（男团 / 女团 / 混团）

每一层级内部，再按 **金牌 → 银牌 → 铜牌 → 奖牌总数** 的顺序比较。

### 四、排序规则

完整比较顺序：

1. 单打金牌数
2. 单打银牌数
3. 单打铜牌数
4. 单打奖牌总数
5. 双打 / 混双金牌数
6. 双打 / 混双银牌数
7. 双打 / 混双铜牌数
8. 双打 / 混双奖牌总数
9. 团体金牌数
10. 团体银牌数
11. 团体铜牌数
12. 团体奖牌总数

### 五、V1.0 暂不考虑的因素

排名仅看三大赛奖牌，不加入：积分计算、对手强度修正、参赛人数修正、比赛轮次修正、世界排名修正、连冠奖励、连续参赛奖励、年龄修正、退役时间修正、主场优势修正、赛事周期修正、胜率或统治力模型。

## 数据范围

- 统计对象：代表中国乒乓球队参加三大赛的运动员
- 数据来源：ITTF、中国乒乓球协会、WTT官方数据
