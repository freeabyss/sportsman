# 国乒荣耀榜 🏓

中国乒乓球队历史成就统计与排名系统。

## 概述

国乒荣耀榜是一个纯前端页面，展示1988年至今代表中国乒乓球队参加正式赛事的运动员的历史成就排名。系统基于赛事等级、奖牌权重和项目权重计算荣耀积分，并提供胜率模型计算统治力指数。

## 核心功能

- **荣耀榜** - 综合排名，支持综合/现役筛选，TOP3卡片展示
- **运动员详情** - 基础资料、荣誉概览、奖牌矩阵、职业赛事记录、比赛历史、对手关系
- **积分分析** - 荣耀积分拆解：赛事贡献、项目贡献的可视化展示
- **赛事浏览** - 赛事列表、赛事详情、项目详情、奖牌分布
- **比赛详情** - 比分展示、局比分、对阵信息

## 排名规则

### 荣耀积分公式

```
荣耀积分 = 奖牌积分 + 成绩积分
奖牌积分 = 赛事等级 × 奖牌权重 × 项目权重
成绩积分 = 赛事等级 × 项目权重 × 排名系数
```

### 赛事等级

| 等级 | 分数 | 赛事 |
|------|------|------|
| S    | 100  | 奥运会、世锦赛、世界杯 |
| A+   | 85   | WTT大满贯、WTT总决赛、全运会 |
| A    | 70   | 亚运会、亚锦赛、全国锦标赛 |
| B    | 45   | WTT冠军赛、公开赛、巡回赛 |
| C    | 20   | 其他正式赛事 |

### 统治力指数

```
统治力 = 生涯胜率×40% + 中国内部胜率×40% + 顶级赛事胜率×20%
```

## 数据范围

- 统计对象：1988年至今，代表中国乒乓球队参加正式赛事的运动员
- 数据来源：ITTF、中国乒乓球协会、WTT官方数据
